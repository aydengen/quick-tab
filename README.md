# QuickTab

一个用快捷键在最近访问的标签页之间切换的 Chrome 扩展。

![QuickTab 宣传图：用 Alt+Q 在带缩略图的标签页之间切换](docs/assets/og-zh.png)

**用法：** 按 `Alt+Q` 打开切换面板；按住 `Alt` 并连按 `Q` 选择标签页，松开 `Alt` 即可切换。
