快捷键没有反应，怎么办？+

先在一个普通网页（如 GitHub）试试。如果仍然没有反应，打开 chrome://extensions/shortcuts，找到 QuickTab，为它设置一个没有被其他扩展或系统占用的快捷键。

Mac 上 Alt 对应 Option（⌥）键。安装后，已打开的页面如果没有响应，可以刷新后再试。

为什么有些页面不能显示面板？+

Chrome 不允许扩展在新标签页、chrome://、Chrome 应用商店和部分 PDF 页面显示面板。在这些页面上按快捷键，会直接切回上一个标签。

为什么需要读取标签页和网站权限？+

读取标签页，是为了显示标题、网站图标并切换页面。网站权限用于截取当前可见页面，作为标签缩略图。没有服务器接收这些数据，源代码也完全公开。

最近标签记录和缩略图使用浏览器本地会话存储，关闭浏览器后清空；快捷键与偏好设置会保留。

免费吗？支持哪些浏览器？+

完全免费，使用 MIT 开源协议。QuickTab 为桌面版 Chrome 开发，支持 Mac、Windows 和 Linux；其他 Chromium 浏览器可能兼容，但尚未逐一验证。手机浏览器无法安装这个扩展。
