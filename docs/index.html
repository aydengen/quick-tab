常见问题

反馈问题
快捷键无效？

先刷新普通网页再试；仍无响应，请在 chrome://extensions/shortcuts 为 QuickTab 设置未被占用的快捷键。

Mac 的 Alt 即 Option。

哪些页面不显示面板？

新标签页、chrome://、Chrome 应用商店及部分 PDF 不显示面板，快捷键会直接切回上一标签。

为什么需要这些权限？

标签页权限用于显示标题、图标和切换标签；网站权限用于生成页面缩略图。数据不上传。

标签记录和缩略图随 Chrome 关闭而清空，快捷键和设置保留。

免费吗？支持哪些浏览器？

免费，MIT 开源。支持 Mac、Windows、Linux 上的桌面 Chrome，不支持手机；其他 Chromium 浏览器未验证。
