# Website icons

Icons are from [Lucide 0.468.0](https://github.com/lucide-icons/lucide/tree/0.468.0/icons), licensed under the [ISC license](./LICENSE.txt).

The local SVG sprite is used by both languages and the privacy pages. Matching symbols are embedded in the simulated page illustrations because SVG images cannot load external resources. Only SVG paths are used; no icon fonts, CDN requests, scripts, or runtime dependencies are added.

Included icons: notebook-pen, palette, github, music, arrow-left, arrow-right, rotate-cw, lock-keyhole, ellipsis-vertical, plus, check, arrow-up-right, corner-down-left, chevron-down, search, house, library, clock, coffee, corner-down-right, square-check, square, git-pull-request, circle-dot, play, shield, folder, file-text, menu, scale, circle.
